# Design System: Industrial-Tech Premium (Ganttagram)

## 1. Vision
A high-performance project management tool for the construction industry that feels like a precision instrument. It combines industrial reliability with modern tech aesthetics.

## 2. Color Palette (Light Mode - Technical Blueprint)
- **Background:** `#f8fafc` (Slate 50) - Clean, bright, professional workspace.
- **Surface:** `#ffffff` (White) - Card and panel background.
- **Primary Text:** `#0f172a` (Slate 900) - High contrast for technical data.
- **Secondary Text:** `#475569` (Slate 600) - For labels and metadata.
- **Accent (Safety):** `#f97316` (Orange 500) - Critical actions and highlights.
- **Secondary (Blueprint):** `#2563eb` (Blue 600) - Interactive elements.
- **Border:** `#e2e8f0` (Slate 200) - Thin, crisp lines.

## 3. Typography
- **Headings:** `Space Grotesk` - Monospace-influenced, technical feel.
- **Body:** `Inter` - Highly readable.
- **Monospace:** `JetBrains Mono` - For dates, IDs, and technical data.

## 4. UI Elements Style
- **Corners:** 6px / 8px.
- **Shadows:** Very subtle, soft shadows (Slate-100 based).
- **Borders:** 1px solid Slate-200.
- **Input Fields:** Precise, subtle borders, high focus contrast.

## 5. Layout Patterns
- **Grid:** Technical blueprint grid background (subtle).
- **Density:** High (compact).

## 6. Design System Notes for Stitch Generation
"Use a clean, bright white or light slate background (#f8fafc) for a professional 'Technical Blueprint' aesthetic. Use high-contrast dark text (#0f172a) and Space Grotesk for headers. Incorporate 'Blueprint Blue' (#2563eb) and 'Construction Orange' (#f97316) as accent colors. The UI should feel like a high-end engineering tool: clean lines, subtle grid overlays, and compact data presentation. Buttons should be solid or outlined with crisp corners."
