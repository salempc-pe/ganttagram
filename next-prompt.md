# Rethought Project Detail & Gantt View (Industrial-Tech Premium)

Create a detailed project view for a specific construction project.
**Style:** Industrial-Tech Premium.
**Environment:** Dark Mode.

**Layout:**
1. **Header:** Project Name (e.g., "Edificio Multifamiliar Miraflores"), Progress Bar, Quick Stats (Days left, Budget health, Active Workers).
2. **Main Content (Split View):**
   - **Left Panel (Task List):** A technical list of tasks with hierarchical structure (Casco, Acabados, Instalaciones). Use thin lines and monospace for IDs/Dates.
   - **Right Panel (Gantt Chart):** A precision Gantt chart. Bars should be styled with 'Blueprint Blue' or 'Construction Orange'. Dependencies should be visible as thin, sharp lines.
3. **Sidebar/Overlay (Task Details):** A slide-over panel for editing task details (Name, Dates, Resource assignment, Comments).

**DESIGN SYSTEM (REQUIRED):**
Use a deep slate background (#0f172a or #1e293b) for a premium dark mode. Use Space Grotesk for technical headers. Incorporate 'Blueprint Blue' (#2563eb) and 'Construction Orange' (#f97316) as the main accent colors. Use a technical, precision-tool aesthetic with thin lines, grid backgrounds, and clear status indicators. Data tables should be compact and highly readable. 

**Technical Details:**
- Language: Spanish (Peru technical terms).
- Tone: Professional, Efficient, Data-Driven.
- Focus: Ease of scheduling and dependency management.
