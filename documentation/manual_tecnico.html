Manual Técnico: Ganttagram

Documentación técnica de arquitectura, desarrollo y despliegue.

React Vite Firebase Tauri Lucide React

1. Introducción Técnica

Ganttagram es una Aplicación Web de una sola página (SPA) construida con React y Vite, diseñada para alto rendimiento en la gestión de datos tabulares y cronogramas. Utiliza una arquitectura orientada a características (Feature-driven architecture) y Firebase como Backend-as-a-Service (BaaS) para persistencia en tiempo real.

2. Entorno de Desarrollo

Para trabajar en este proyecto, se requiere el siguiente software:

  • Node.js: v18.x o superior.
  • Manejador de paquetes: NPM (incluido con Node).
  • Tauri Dependencies (Opcional): Si se compila para escritorio (Windows/macOS/Linux), se requiere Rust y las dependencias de Tauri (Webkit2Gtk en Linux, Visual Studio Build Tools en Windows). 
# Instalación de dependencias
npm install

# Ejecución en modo desarrollo
npm run dev

# Construcción para producción (Web)
npm run build

3. Arquitectura del Proyecto

El código se organiza siguiendo el patrón de Bounded Contexts dentro de src/features:

UI Components <--> Custom Hooks <--> Services (Firebase)
Directorio Propósito
src/features/ Contiene la lógica y UI específica de cada dominio (auth, projects, tasks, etc).
src/shared/ Componentes de UI comunes (botones, inputs, modales) y utilidades generales.
src/services/ Configuración de servicios externos (Firebase Firestore/Auth).
src-tauri/ Configuración de la aplicación nativa para escritorio.

4. Persistencia y Backend (Firebase)

Ganttagram utiliza Firebase para gestionar la autenticación y la base de datos NoSQL.

4.1. Firebase Config

La configuración se carga mediante variables de entorno (VITE_FIREBASE_*). El archivo clave es src/services/firebase/config.js.

4.2. Seguridad (Firestore Rules)

Las reglas de seguridad están configuradas para restringir el acceso solo a usuarios autenticados, excepto para la lectura de perfiles básicos necesaria para el inicio de sesión.

match /{document=**} {
  allow read, write: if request.auth != null;
}

5. Gestión del Estado

Se utiliza una combinación de:

  • React Hooks: useState y useEffect dentro de hooks personalizados (ej: useProjects) para manejar la lógica de negocio.
  • Firebase Snapshots: Para actualizaciones en tiempo real sin necesidad de recargar la página.
  • Context API: Para el estado global de autenticación (AuthContext).

6. Estilo y Diseño

El sistema de diseño "Industrial-Tech Premium" se implementa mediante CSS puro con variables en index.css. Se prioriza una estética compacta y de alta densidad de datos, ideal para herramientas de ingeniería.

  • Colores: Slate 50-900 para la base, Blueprint Blue (#2563eb) y Construction Orange (#f97316) para acentos.
  • Tipografía: Space Grotesk (Títulos) e Inter (Cuerpo).

7. Despliegue y Distribución

7.1. Aplicación Web

La web se despliega automáticamente en Netlify mediante el archivo netlify.toml que maneja las redirecciones para el Router de React.

7.2. Aplicación Escritorio (Tauri)

Se utiliza Tauri para empaquetar la web en un ejecutable nativo ligero. El motor de renderizado es el WebView del sistema operativo host, lo que reduce el tamaño del ejecutable significativamente.
